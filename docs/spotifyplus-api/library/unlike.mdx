# Library.unlike()

Removes a track from liked songs.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Library.unlike(track: <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a>): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can remove the current song from liked songs.

```ts
// Remove the current song from liked songs.
const track = SpotifyPlus.Player.getCurrentTrack();
if (!track.uri) return;

if (SpotifyPlus.Library.isLiked(track.uri)) {
  SpotifyPlus.Library.unlike(track.uri);
  SpotifyPlus.toast(`Unliked ${track.title}`);
}
```

## Parameters

`track`

<Badge href="/docs/types/spotify-uri-input">SpotifyUriInput</Badge> <Badge variant="danger">Required</Badge>

The Spotify URI of the track.

## Returns

`void`

Returns after the local library accepts the change.

## Remarks

Equivalent to removing that track from the library.


This is a synchronous local call. It reads or updates Spotify's local library and throws on service errors. Spotify handles account synchronization separately.
