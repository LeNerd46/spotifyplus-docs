# Player.cycleRepeat()

Cycles the repeat state from off -> repeat -> repeat one -> off.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Player.cycleRepeat(): void</span>
</CodeBlock>

## Examples

The following example will cycle the repeat state when the user presses a button.

```tsx
import { Text } from 'spotifyplus/react';

import { useEffect, useState } from 'react';
import { SpotifyPlus, type RepeatMode } from 'spotifyplus';
import { View, Text, Pressable } from 'spotifyplus/react';

const Screen = () => {
    const [repeat, setRepeat] = useState<RepeatMode>();
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        const load = () => {
            const state = SpotifyPlus.Player.getState();
            setRepeat(state.repeat);
            setLoading(false);
        };

        load();
    }, []);

    const cycleRepeat = () => {
        SpotifyPlus.Player.cycleRepeat();
        const state = SpotifyPlus.Player.getState();
        setRepeat(state.repeat);
    };

    if (loading) return <Text>Loading...</Text>;

    return (
        <View style={{ flex: 1 }}>
            <Text>Repeat is set to {repeat}</Text>

            <Pressable onPress={cycleRepeat}>Cycle Repeat</Pressable>
        </View>
    );
};

export default Screen;
```

## Returns

`void`

Returns after Spotify acknowledges the local command. Playback and state events may arrive later.


This is a synchronous local call. It throws if the player is not ready or Spotify rejects the command. Use `try/catch` for errors. Playback state and events can update after the call returns.
