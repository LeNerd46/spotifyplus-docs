# Player.play()

Resumes the current track.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Player.play(): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can resume playback only when Spotify is paused.

```ts
// Resume playback only when Spotify is paused.
const state = SpotifyPlus.Player.getState();
if (!state.isPaused) return;

SpotifyPlus.Player.play();
SpotifyPlus.toast('Playback resumed');
```

## Returns

`void`

Returns after the play request completes.


This is a synchronous local call. It throws if the player is not ready or Spotify rejects the command. Use `try/catch` for errors. Playback state and events can update after the call returns.
