# Player.skipPrevious()

Skips to the start of the track or to the previous track.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Player.skipPrevious(): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can return to the start of the current song, or go to the previous one.

```ts
// Return to the start of the current song, or go to the previous one.
const state = SpotifyPlus.Player.getState();
if (!state.trackUri) return;

SpotifyPlus.Player.skipPrevious();
const updated = SpotifyPlus.Player.getState();

console.log('Now playing:', updated.trackUri);
```

## Returns

`void`

Returns after the skip request completes.

## Remarks

This may not work until the user has played a song (i.e. it may not work if the user just opened Spotify and has not played a song yet).

This is a synchronous local call. It throws if the player is not ready or Spotify rejects the command. Use `try/catch` for errors. Playback state and events can update after the call returns.
