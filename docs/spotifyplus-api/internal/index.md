# Internal Spotify APIs

All the methods inside of `SpotifyPlus.Internal` are reverse engineered Spotify API endpoints. As I have no control over these endpoints, they are subject to change and may stop working at any point. 

If you find any more private Spotify API endpoints that you would like to see added, please feel free to make an issue on GitHub requesting it. These are fairly hard to find and make usable, so I'm sure there are a lot that I am missing.
