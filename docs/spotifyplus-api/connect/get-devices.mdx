# Connect.getDevices()

Lists available Spotify Connect devices.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Connect.getDevices(): <a href="/docs/types/api-types#connectdevice">ConnectDevice</a>[]</span>
</CodeBlock>

## Examples

The following example shows how an extension can find devices that can receive playback.

```ts
// Find devices that can receive playback.
const devices = SpotifyPlus.Connect.getDevices();
const available = devices.filter(device => !device.isDisabled);

for (const device of available) {
  console.log(`${device.name}: ${device.isActive ? 'active' : 'available'}`);
}


if (available.length === 0) SpotifyPlus.toast('No Connect devices found');
```

## Returns

`ConnectDevice[]`

The available devices.


Returns Spotify's latest observed device snapshot synchronously. Throws until the Connect service has supplied its first snapshot. Device transfer remains asynchronous.
