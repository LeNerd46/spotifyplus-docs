# Playlists.addTracks()

Adds tracks to a playlist.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Playlists.addTracks(playlist: <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a>, tracks: <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a>[]): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can add the current track to the user's first saved playlist.

```ts
// Add the current track to the user's first saved playlist.
const saved = await SpotifyPlus.Library.list({ type: 'playlist', limit: 1 });
const playlist = saved.items[0];
if (!playlist) return;

const track = SpotifyPlus.Player.getCurrentTrack();
if (!track.uri) return;

SpotifyPlus.Playlists.addTracks(playlist.uri, [track.uri]);
SpotifyPlus.toast(`Added to ${playlist.name}`);
```

## Parameters

`playlist`

<Badge href="/docs/types/spotify-uri-input">SpotifyUriInput</Badge> <Badge variant="danger">Required</Badge>

The playlist to read or change.

`tracks`

<Badge>SpotifyUriInput[]</Badge> <Badge variant="danger">Required</Badge>

The track URIs to add.

## Returns

`void`

Returns after the tracks are added.


This is a synchronous local modification. It throws if Spotify rejects the operation. The result acknowledges the local playlist change; Spotify synchronizes the account separately. Playlist loading with `Playlists.get()` remains asynchronous.
