# Playlists.delete()

Removes a playlist from the current user’s library.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Playlists.delete(playlist: <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a>): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can select a playlist that belongs to the current user.

```ts
// Select a playlist that belongs to the current user.
const saved = await SpotifyPlus.Library.list({ type: 'playlist' });
const owned = await Promise.all(saved.items.map(item => SpotifyPlus.Playlists.get(item.uri)));
const playlist = owned.find(item => item.ownedBySelf && item.name === 'Songs to revisit');
if (!playlist) return;

// This removes the playlist from the user's library.
SpotifyPlus.Playlists.delete(playlist.uri);
SpotifyPlus.toast('Playlist removed');
```

## Parameters

`playlist`

<Badge href="/docs/types/spotify-uri-input">SpotifyUriInput</Badge> <Badge variant="danger">Required</Badge>

The playlist to read or change.

## Returns

`void`

Returns after the removal request completes.

This is a synchronous local modification. It throws if Spotify rejects the operation. The result acknowledges the local playlist change; Spotify synchronizes the account separately. Playlist loading with `Playlists.get()` remains asynchronous.
